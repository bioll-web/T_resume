# 谭佳庆 · 交互式老虎机简历

这是一个独立于 Crossing 项目的个人求职主页，采用 Crossing 系统设计规范板的配色与几何视觉语言。

- `index.html`：纯 HTML/CSS/JavaScript，无构建依赖；老虎机拉杆、三列转轮、五类档案、日夜模式与移动端适配。
- `assets/Tan_Jiaqing_Resume.docx`：网页可下载的 Word 简历。

## 公开访问

启用 GitHub Pages 后访问：https://bioll-web.github.io/T_resume/

如尚未启用：打开仓库 **Settings → Pages → Build and deployment**，选择 **Deploy from a branch**，分支为 `main`，目录为 `/ (root)`，保存即可。

## 说明

已实现的产品原型、工程技术栈与尚在学习/规划的算法方向明确分开。仓库仅用于简历，不修改任何已有 Crossing 项目。
